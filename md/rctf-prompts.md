1. Kiểm tra chẵn lẻ

- R: Bạn là người hướng dẫn Python.
- C:T mới học lệnh `if`.
- T:Viết code kiểm tra số chẵn hay lẻ.
- F: Trả lời bằng code ngắn.

Kết quả AI mẫu:

```python
n = int(input("Nhập số: "))
print("Chẵn" if n % 2 == 0 else "Lẻ")
```

AI còn thiếu:Nhập chữ sẽ bị lỗi.

2. Tính điểm trung bình

- R: Bạn là trợ giảng Python.
- C: T đang học phép tính.
- T:Tính điểm trung bình 3 môn.
- F:Viết code đơn giản.

Kết quả AI mẫu:

```python
a, b, c = 7, 8, 9
print((a + b + c) / 3)
```

AI còn thiếu:Chưa kiểm tra điểm có hợp lệ (0–10) không.

3. Tìm số lớn nhất

-R: Bạn là người hướng dẫn Python.

- C: T đang học danh sách.
- T:Tìm số lớn nhất trong danh sách.
- F:Viết code kèm kết quả.

Kết quả AI mẫu:

```python
so = [3, 7, 2, 9]
print(max(so))  # 9
```

AI còn thiếu: Danh sách rỗng sẽ bị lỗi.
